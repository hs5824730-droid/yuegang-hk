# 全局设计工具与网站应用

安装日期：2026-10-23。全局指当前 Windows 用户 Morty 的共享 Agent 技能目录，新建或重新启动 Agent 会话后可发现，不改变其他 Windows 用户的配置。

## 已安装

1. `C:\Users\Morty\.agents\skills\design-toolkit`：本地编写的设计工具指南，覆盖截图中八项工具。根据实际设计问题选择工具；它不是八个项目官方发布的 Skill。
2. `C:\Users\Morty\.agents\skills\shadcn`：来自 [官方仓库 skills/shadcn](https://github.com/shadcn-ui/ui/tree/main/skills/shadcn) 的 Skill，21 个上游文件逐个校验 Git blob SHA 后安装，附上游 MIT 许可。

shadcn 安装适配：上游 `SKILL.md` 的 `user-invocable` 字段移入 metadata，正文未改；保留上游 `agents/openai.yml`，另提供符合 Cindy 规范的 `agents/openai.yaml`。上游原始数据及校验清单位于 `data/skill-install/`。两个 Skill 均通过 Cindy 的 quick_validate；本地引用文件齐全。

已有的其他设计 Skills 没有覆盖或删除。可在新会话中说“用 design-toolkit 改善这个页面”，shadcn 项目则可使用 shadcn Skill。

## 八项工具分别是什么

| 工具与官方来源 | 类型 | 本次处理 |
| --- | --- | --- |
| [Radix Colors](https://www.radix-ui.com/colors/docs/overview/installation) | 配色库 | 加入全局使用指南，并安装到当前网站，实际应用 Sand / Orange 状态色 |
| [Fontsource](https://fontsource.org/docs/getting-started/install) | 自托管字体包 | 加入指南；当前网站安装两套可变字体，替换 Google Fonts 外链 |
| [shadcn/ui](https://ui.shadcn.com/docs/skills) | 组件系统及官方 Skill | 官方 Skill 安装到全局；当前网站保留已有组件，未强制迁移 Tailwind |
| [Rough.js](https://roughjs.com/) | 手绘风格 SVG / Canvas 图形库 | 加入全局指南，需要手绘图形时按项目安装 |
| [Simple Icons](https://simpleicons.org/) | 品牌图标库 | 加入全局指南；当前网站的通用操作图标继续使用 lucide |
| [Mermaid](https://mermaid.js.org/intro/getting-started.html) | 结构化图表工具 | 加入全局指南，优先使用现有 Cindy Mermaid 插件 |
| [GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats) | GitHub 统计卡服务 | 加入全局指南，用于开发者文档，不放入房东广告页面 |
| [Markdown Badges](https://github.com/Ileriayo/markdown-badges) | Markdown 徽章目录 | 加入全局指南；属于引用素材，无需运行时安装 |

前端库按项目记录在 `package.json` 与 `package-lock.json`；全局安装的是可复用的技能指导。没有用 `npm install -g` 把库假装变成全局 Skill。

## 当前网站可见变化

- 亮橘色主按钮配深色文字，与品牌图标、优惠板块保持一致。
- 使用成体系的中性色与橘色选中态，输入框焦点清楚，城市选中有加粗边框反馈。
- 使用真实可变字重，统一中英文排版。中文手机标题 31px、英文 27px；输入框 16px。
- 字体由网站自身提供；iPhone 优先使用系统 PingFang SC，减少下载。字体许可随站点保存在 `public/fonts/`。
- 首页现有服务切换、图片淡变、城市横向导航、三步咨询流程保持有效。
