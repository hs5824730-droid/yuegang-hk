## 接粉规则

1. 新客户发到公共邮箱，按江承裕 → 江牧 → 江鹏轮流分配。
2. 有可信、已保存的人员归属时，沿用该人员；发到明确人员入口的邮件归对应人员。
3. 同一邮件往来持续归原负责人；邮件重复投递、抓取重试、机器人重试不重新占用轮次。
4. Telegram 与 Signal 均显示接粉人员。只展示客户实际提供的信息，邮件里没有电话或房产城市时标为未提供。
5. 邮件的接粉归属必须持久保存；后续回复按邮件会话关联，不通过姓名或邮件主题猜测客户身份。
6. 员工回复的 From、Reply-To 均应为 contact@eucove.com，默认签名使用统一客服身份。实际信头与收件方显示效果需要验证。
