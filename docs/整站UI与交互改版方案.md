# 桉湾整站 UI 与交互审阅方案

状态：供 Claude 恢复后统一审核，尚未由 Claude 审阅或批准。本轮由 Codex 做已授权的文字减负、活动提示及状态呈现，不执行整站风格重做。保留六导航、橘白品牌、手机优先和现有信息架构。

## 本轮可直接验收

- 精简的是语言，不是把主要内容藏起来。出租托管与买卖页主要工作、流程、授权说明、服务对比和场景默认直接展示；不机械要求减字50%，仅真正FAQ保留展开；团队简介保持普通段落直接显示。用户已明确撤销「约28人」口径，公开公司总人数不作表述，也不以展示成员数推断公司规模。
- 首页与出租页首屏增加钥匙图标活动票签，明确「首套免出租佣金」，保留第二套半价、免费搬家与2027年2月。活动区仍直接说明同房东委托顺序、管理费另约、销售/其他费用不减免、搬家用于入住该房屋的房东或租客及安排确认。
- 买卖页按业务方明确指令写「佣金比同行低30% / Commission 30% lower than competitors」「免费咨询」「买卖前期不收取服务费」。这属于用户确认的商业口径，未作外部行业费率核验；不补造具体费率、比较表、最低价、所有同行或监管背书，不扩到出租管理或第三方费用。
- 首页其他服务五项增加具体短行；买卖说明准备推广/报价沟通与需求筛选/看房，购房咨询侧重城市区域预算和购房范围。真实链接与服务参数保留。
- 按用户最新纠正，在线看房出租栏只展示明确核实在租记录，去掉状态筛选和待确认文案；已出租/未核实只留内部档案，不重标为可租。已成交参考保持成交性质，不预约该房源。

## 跨页约束

继续六主导航：首页→出租与托管→买卖房屋→置业顾问→在线看房→关于我们。不得因布局方便合并或删除业务。保留当前页唯一高亮、双语、浏览器返回和房间/房源深链。

手机正文14–16px，输入16px；主要点击区至少44px。先让用户看到业务、价格性质、当前状态和下一步，再提供明细。一个主动作可配一个次动作；不把同一业务在连续区块反复解释。空配置、空筛选、网络错误要有可用下一步；不伪装完成状态。

初步字数预算为中文默认可见内容，英文按信息量控制，必须实际检查换行；不是限制完整合同/隐私文本的字数。关键优惠和费用边界不因预算隐藏。展示图只说明服务或真实房况，不冒充公司案例/历史成果。

## 数据与内容依赖

当前API没有 availabilityStatus，UI不据日期或缺失字段推断可租。建议字段为 available/leased/unknown；出租只允许明确available，leased/unknown/缺失全部不展示，公网页面不写待确认，kind=sold按已成交。详见 `data/design-review/viewing-availability-ui-contract.md`，需由Lead转交Sol核对正式契约后对齐。扩容真实36租和约12售由Sol负责，本轮不制造数量或占位房源。

自有买卖案例、客户评价仍缺真实资料，不能将公开成交参考说成经手案例。二维码未实扫，江鹏两码是否同目标尚无法确认；不影响按实际提供条目顺序展示，不能虚构不同微信账号。
