# 庭院实时 3D 预览

2026-11-03：用户要求将刚提供的庭院设计图建立为可交互的 3D 可视化。原始输入只有图片，没有 CAD、SketchUp、GLB、测量或材质文件。本轮使用项目已有的 Three.js 重建程序化空间示意，不将图片贴到平面上冒充三维模型，不声称恢复了原始或准确尺寸的模型。

## 方案与交互

九张图片映射到八种布局；第一和第三张是同一个庭院的不同视角，模型共用，第三张默认俯视。其他分别为狭长庭院、水景木平台、廊架多功能院、遮阳伞餐区、简约水景院、狭长阳台和小院。

2026-11-03 用户追加要求默认打开 3D。进入房屋服务庭院区即显示“3D 空间预览”，选择缩略图即可更换模型；提供鸟瞰、俯视、近景、左右转向、缩放与复位。保留“设计图”及完整原图弹窗。两站共用布局与模型，外层继承明亮/暗黑主题。

同轮按用户截图要求，前面的四张服务卡片在电脑端改为一行四张（宽度大于 1023px），平板两列、手机一列；卡片内项目列表改为单列，并收紧标题、图标和内边距以适应四列宽度。

手机默认不占用触摸滚动，点“启用拖动”后单指旋转、双指缩放；结束拖动或 Escape 恢复页面滚动。按钮提供等价操作。无 WebGL 或上下文丢失时提供设计图回退和重载。

## 实现

- `src/components/garden-scene.ts`：布局参数、地台铺装、弧形围坐、织面休闲椅、木平台、吧台/灶台/水槽龙头、树木、绿植、廊架、桌椅、遮阳伞与水景几何；程序化木纹、石纹、织物与地毯纹理。
- 静态建筑与家具按材质合并，叶片使用实例化渲染；无需外部模型、素材 CDN、模型生成 API 或新增依赖。
- `src/components/garden-engine.ts`：单个 WebGLRenderer、正交相机、OrbitControls、日光阴影、有限视角与缩放、ResizeObserver、可见性处理、上下文失败及资源释放。
- 3D 组件挂载时动态导入引擎，默认进入 3D；选择原图会释放 renderer，回到 3D 时重新创建。切换方案复用一个 renderer。无持续动画循环，仅在相机/场景/尺寸变化或重新可见时绘制；静态阴影冻结。
- DPR 桌面最多 2、窄屏/触屏最多 1.5，并限制画布到 200 万像素。离开 3D 时释放几何、纹理、材质、阴影与 WebGL 上下文。

## 验证

- `npm run build:com`、`npm run build:net`：TypeScript、正式双站打包与 Worker dry-run；不部署。
- 可复现检查：启动本机预览后运行 `node scripts/garden3d-review.mjs`；可用 `GARDEN_REVIEW_URL` 指定地址，`PW_CHANNEL` 选择浏览器，`PW_HEADLESS=true` 无界面运行。
- Edge 模拟两站主题 × 中英文 × 320/390/1440px 共 12 组：默认 3D、原图切换释放画布、九图切换且复用同一画布、八种不同场景、视角变化、缩放复位、鼠标/触屏拖动、原图弹窗回退、无横向溢出与运行错误均通过。
- 单独模拟 WebGL 上下文丢失，检查错误回退、重新加载仅保留一个画布、切回照片释放画布，已通过。
- 默认 3D 与服务卡片调整后 `npm run build` 通过；两站主题 × 中英文 × 320/390/768/1024/1440px，共 20 组默认状态、卡片行数与无横向溢出检查通过。
- 截图及记录在忽略的 `data/` 目录。模拟手机交互不等于实体手机性能验证。
