# 房东广告首页与手机体验

2026-10-23。目标是让广告进入的华人房东了解出租/长期托管并提交咨询。

## 已实现

- 首屏明确“澳洲房产出租与托管”，说明找租客与长期管理的差异。主要入口为出租与托管咨询；买卖、3D 与历史房源保留在后续内容。手机不再先划过整块大图才找到按钮。
- 橘色与白色为主，深灰正文。住宅图支持业务氛围，图注与页脚标明为编辑配图。
- 首套免出租佣金、第二套半价，同时展示同一房东、出租佣金和截至 2027 年 2 月的边界，链接至具体说明。
- 手机底部导航、页面返回、底部筛选面板、全屏分步咨询；城市选择与服务切换有反馈。删除城市时钟及时差。
- 公开咨询删除中介管理问题；服务仍为仅招租、长期托管、出售、买房四项。手机号/WhatsApp 前后端同样校验；未询问的 currentlyManaged 存 null，已有业务限制不变。
- 面板进入/退出、表单前进返回、按钮按压、服务/城市切换与 FAQ 过渡。减少动态效果时关闭动画，首屏内容不依赖动画结束。
- 失败保留内容和重试 requestId，服务端成功确认后显示成功。隐私链接另开标签，语言切换保留输入，浏览器返回关闭咨询面板。

## 公开项目参考

- [Ionic tabs](https://ionicframework.com/docs/api/tabs)：顶层导航与真实路由状态对应。
- [Vaul](https://vaul.emilkowal.ski/)：移动面板及遮罩的交互参考。
- [Motion 布局动画](https://motion.dev/docs/react-layout-animations)：状态连续性与退出动画原则。
- [Google 落地页指南](https://support.google.com/google-ads/answer/6238826?hl=en)：广告与落地页信息一致、清晰操作入口。

本轮借鉴交互原则，实际使用现有 React 与 CSS 实现，没有安装 Ionic、Vaul 或 Motion，也没有复制其品牌素材。没有承诺转化率或广告审核结果。

## 验证

主控在 375×667、390×844、430×932 和 1440×960 上检查首页中英两种语言，主咨询按钮均在首屏可见，横向溢出为 0。并检查服务、优惠、关于、房源、历史、海外与图片署名页的手机布局。

表单浏览器验证包括城市必选、拒绝邮箱、语言切换保留姓名、失败保留数据、重试沿用 requestId、成功显示、Esc 与浏览器返回关闭、滚动锁释放及减少动画。失败与重试使用拦截模拟响应；另在 127.0.0.1:3002 的隔离测试服务完成实际 POST，返回 201 并显示成功，测试库与真实数据分离且 DISABLE_TELEGRAM=true。没有向真实客户库或 Telegram 发送测试消息。后台独立自动测试覆盖实际持久化、幂等、权限和通知重试。

具体数据：`data/design-review/checks.json`、`production-checks.json`。截图：同目录 `mobile-zh.png`、`desktop-zh.png`、`fixture-success.png` 等。服务切换键盘操作、城市入口联动、两种语言布局也已通过。浏览器为 Edge；这些结果不等于真实 iPhone Safari 的键盘和系统手势实机验收。

## 投放前尚需补齐

当前地址只用于局域网预览。公开广告需要正式域名及 HTTPS 部署、选定品牌、WhatsApp 号码、完整公司/团队资料，以及广告平台与来源、有效提交统计的配置。优惠具体截止日和计算细则需确认。外部房源检索因原 Worker 权限确认超时没有取得记录，页面不展示虚构记录。

本轮没有接入第三方广告像素、购买广告或注册域名。把咨询按钮点击与真实成功提交区分开，待平台确定后接入归因。
