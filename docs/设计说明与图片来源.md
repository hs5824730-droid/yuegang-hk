# 桉湾 EUCOVE 前台设计与图片来源（2026-10-23）

## 当前方向

- 用户选择 B「桉湾 / EUCOVE」，橘色与白色，首页优先解释澳洲房产出租与托管，为房东咨询提供入口。买卖房与历史记录是次级入口。
- 品牌橘 `#FF6A2B` 用于标记、主按钮与优惠板块，按钮采用深色字；`#C2410C` 用于白底小字与焦点标记。中性色使用 Radix Sand，橘色状态底使用 Radix Orange，主按钮文字对比度约 5.71:1（sRGB）。
- 英文为本地托管的 Instrument Sans Variable；中文在 iPhone 优先使用 PingFang SC，其他设备按需加载 Noto Sans SC Variable。字体由 Fontsource 管理，不再依赖 Google Fonts 外链。手机首页主标题中文 31px、英文 27px，输入框维持 16px。
- 品牌图形来自方案 B 的海湾线与中心点。首页照片右下有橘色标记，局部圆角与标志呼应；渐变只用于照片底部保证文字可读。
- 沿用已有、可追溯的住宅与城市编辑配图，没有把氛围图变成实际房源照片。

## 首页与交互

- 首屏明确“澳洲房产 / 出租与托管”，可切换仅招租或长期托管，图片、说明、咨询按钮同步；点击咨询带入所选服务。图片淡变与下划线移动，无自动轮播。
- “每一步，我们做什么”以出租前、找到租客、入住后三个标签介绍真实服务范围。入住后的服务明确属于长期托管，咨询入口带入托管。
- 优惠区域为橘色底与白色计算面板，可调 1–4 套，逐套展示免出租佣金、半价、正常标准，不虚构货币节省金额。
- 手机保留底部导航、紧凑页头；五城缩略图使用原生横向滑动，选中项保持在横向可见区域，不抢占页面纵向滚动。方向键、Home、End 可操作服务及城市标签。
- 关于页继续使用简洁的城市标签，与首页图片导航区分。全站城市图集均不展示时间或时差。
- 减少动态效果时停止标志描线与可见过渡。无持续循环动效、鼠标跟随或强制滚动。

## 咨询表单

- 选择服务 → 城市与房屋 → 联系方式。公开选项仅招租、长期托管、出售、买房，搬家不作为单独服务。
- 已按用户要求移除“是否由其他中介管理”的公开问题，省略时后端保留 null；不承接转中介的业务口径仍在服务说明中。
- 联系方式只接受电话或 WhatsApp，不收邮箱；买家第二步为意向城市与区域。
- 手机全屏抽屉、底部动作区，跟随可视视口处理键盘；支持 Esc、浏览器返回、焦点锁定及关闭后焦点恢复。
- 每步校验；重试沿用 requestId；语言切换保留输入；服务器确认才显示成功。

## 内容边界

- 同一房东按委托房屋顺序，首套免出租佣金、第二套半价，优惠至 2027 年 2 月。页面明确仅出租佣金；确切截止日、管理费与其他细则由书面协议说明。
- 免费搬家仅为出租配套，范围和次数由助理确认。
- 不编造代理房源、成交记录、评价、履历或响应时长。公开市场参考仅在非生产模式提供，来源与核实时间独立注明，不计作自己的成交案例。
- 3D 示意与真实导览区分，不宣称当前已有真实房源导览。
