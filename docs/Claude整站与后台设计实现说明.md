## 视觉系统

规则写在 `src/eucove-ds.css` 文件头，样式限定在 `.ds` 范围内。

- 颜色：白底，暖浅灰带（#f2f1ee），近黑面板（#0f0f0e）。橙色只用于主操作、编号和当前状态。
- 字体：Instrument Sans 可变字体，改为加载宽度轴（`wdth.css`）。数字和英文标题使用 75–84% 窄体，中文标题使用 Noto Sans SC。
- 形状：前台控件一律直角，靠 1px 细线分隔；图标是细线描边方框。
- 图片：素材多为 3:2，图框按原图比例设定；方图和竖图单独给比例（5:4、4:5）。在线看房的房间照片用 `contain` 完整显示，背后衬一层同一张图的模糊放大作氛围。
- 动效：只播一次。包括分屏进场、内容上浮、图标描线、房源切换时的擦入。悬停效果只在支持悬停的设备上生效；开启减少动态效果时全部静止；没有循环动画，也不接管滚动。

## 已实现页面

- `/services`：分屏首屏（`A$0` 首套出租佣金，右侧有活动卡）；页内吸顶目录（只做锚点跳转，不收起内容）；优惠 01/02/03 及边界说明；招租三步（每步单列一行“您决定”）；深色长期托管区；两种委托对比卡；常见问题；收尾咨询区。
- `/buy-sell`：分屏首屏（30%），右侧三行列出“佣金比同行低30% / 免费咨询 / 买卖前期不收取服务费”；卖房、买房两张完整卡；三个服务场景（我们做 / 您决定）；三步开始；成交参考入口（写明公开市场数据，不是我们的案例）；常见问题。
- 首页：保留原全幅首屏。其后依次为：三条品牌承诺（交给我们，省心安心 / 减价不减服务 / 一次合作，终生合作）；三项业务大图卡；优惠条（保留 `/?service=rent&offer=1` 链接）；委托对比；五项其他服务（直接展示，各一行具体说明）；四步流程；常见问题；简短团队介绍（10 位成员的圆形头像加名字，不写成立年份或人数）；收尾咨询区。
- `/advisory`：分屏首屏（`A$0` 上门评估费）；四项服务方块；装修项目全部直接展示（不再折叠）；五步流程时间线；效果参考图改为每张一个短标签加“示意”角标，删除了原来的长免责声明。
- `/viewings`：建筑参考式分屏。左侧完整照片，配位置、当前房间、`01 / 36` 大编号；右侧黑色面板，含窄体大写地址、大号价格及价格性质说明、卧室/卫浴/车位、可入住时间、房间缩略图、方形左右箭头、预约按钮和地图。下方是细线房源条。租/售切换、城市筛选、URL 记忆和 available 状态守卫均沿用原逻辑。
- `/about`：分屏首屏（6 座重点城市）；三条价值；10 位成员全部直接展示（照片、城市、姓名、职责、完整简介，可按城市筛选，没有逐人咨询按钮）；城市咨询入口。
- `/offer`：改为同一套分屏首屏，加上与 `/services` 共用的优惠区。
- 全站收尾咨询区（`CtaBand`）统一为“深色文案 + 3:2 图片”样式，页面描述去掉了成立年份。

## 后台

样式在 `src/admin-redesign.css`，没有改业务逻辑、API、鉴权或游标。

- 深色侧栏，当前页用橙色细线标示；页面标题下加细线分隔。
- 概览数字改为窄体大号，四格共用细线。
- 表格表头小号大写，状态改为圆点标签，当前行左侧有橙线。
- 手机端咨询卡：名字和状态在第一行，日期、城市、服务合成一行，负责人在下，按钮通栏。
- 渠道分流：队列/记录切换和 WhatsApp/微信切换都改成分段控件；启用改为开关；仍是简单表格加拖柄、上下移动、编辑、删除。保存栏只在有未保存更改时吸底并标橙。
- 登录页改为深色背景。所有按钮保持至少 44px 高，满足触屏点击。
