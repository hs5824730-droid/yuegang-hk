# 房屋服务：庭院灵感展示

2026-11-03，用户提供十张庭院、露台和阳台设计图片，要求清除中间与底部全部水印，并加入刚完成的房屋服务页面，由本轮自行设计排版。第六张与第十张内容一致，去重为九张展示图；第一张和第三张为同一方案的不同视角，保留细节视角。

## 页面

- 中英文 `/zh/home-services`、`/en/home-services`，服务卡片后新增庭院灵感展示区。
- 两站使用同一组件及布局，继承 `.com` 明亮、`.net` 暗黑主题变量。
- 桌面主图加九张方案缩略图，窄屏改为上下布局，缩略图三列。
- 缩略图按钮可用键盘切换；主图打开原生 dialog，提供完整图片、关闭按钮、Escape 关闭及焦点返回。
- 园艺卡片提供页内入口；展示区预约按钮使用已有的 `service=garden` 登记入口。
- 文案明确为设计灵感，不能被当作桉湾完工案例或真实房源；实际服务以评估和确认报价为准。

## 素材与处理

来源是用户本轮提供的图片，其中原署名为“庭院设计良境 / LIANGJING”，带“小红书”水印。保留此内部来源记录，不能因为清理水印而宣称为桉湾原创设计。

Art/Core 通道的最初请求返回 `SUBMISSION_OUTCOME_UNKNOWN` 网络错误，未重新提交该通道。改用内置 image_gen 图片编辑工具完成处理，原始输出保留在工具返回的生成目录。

编辑提示词：仅清除图片中间与底部的全部“@庭院设计良境 | 小红书”、白色角标、所有“LIANGJING”署名；自然补全被遮挡的材质；保留全部设计、上下视图、几何结构、家具、绿化、配色和构图，不添加文字或标识，不裁掉设计内容。

网站文件位于 `public/img/home-services/garden/design-1.webp` 至 `design-9.webp`。工具生成后仅转换为 WebP 供网站加载；完整图片在放大窗口保留，列表预览使用 CSS 取景。

本轮不涉及真实咨询提交、Telegram/Signal 通知、后台业务或数据库改动。
